# Boo Bash booth guide

For whoever sets up the Panther Prowl booth and the volunteers running it.

## Before the event: set up each booth device (5 minutes)

1. **Open the game** in Chrome (or Safari on an iPad).
   - At the booth, the game must already be loaded. Event Wi-Fi is unreliable,
     so don't count on loading it there.
   - Hosted on thinkinbits.site: open it once while you still have internet.
   - Running from a laptop: start the local server (see the README) and open
     `http://localhost:8000`.
2. **Open staff mode:** on the title screen, tap the **moon** (top-right
   corner) **5 times quickly**, then enter the PIN. The default PIN is `1031`.
3. In staff settings:
   - **Change the PIN.** The default is public, because the code is on GitHub.
   - Tick **This device gives out prizes** and give it a **station name**
     ("Booth A", "Booth B"...). The station name appears on every prize
     screen.
   - Check the **round length** (90 seconds is the default) and the **prize
     thresholds**.
   - Tick **Kiosk mode**. The game then goes back to the title screen when
     nobody's playing, and shows the high scores between players.
4. Press **Save and close**.
5. Tap the **fullscreen** button (bottom-right on the title screen).
   - On an iPad, use Share → **Add to Home Screen** instead, and open the
     game from that icon.
6. At the start of the night, if the device was used for practice: staff mode
   → **Erase tonight's scores** (tap it twice).

## During the event

1. The player pays $2, then taps **Boo Bash Challenge**.
2. They play one round (90 seconds). Getting caught doesn't end the round; it
   just costs time.
3. The **prize screen** appears. Check that:
   - the **tier** (Bronze / Silver / Gold / Legendary Panther) is on screen,
   - the **station name** is this booth's,
   - the **clock is ticking** and shows the current time. A screenshot from
     someone's phone shows a frozen, old time.
4. Hand over the prize for that tier. If you're keeping a paper list, write
   down the **play number** and **prize code**.
5. The player taps **Continue**. If they made the top 10, they enter 3 letters
   (initials only, never names).

**Someone shows you a phone screen instead of the booth device?** Prizes only
come from booth devices. On anyone else's device, the game says "Prizes are
won at the Boo Bash booth" and shows no code.

**Checking a code later:** staff mode → **Check a prize: play number**. It
shows that play's time, score, tier and code. The **prize log** lists every
Challenge play on this device.

## If something goes wrong

- **The game froze or looks wrong:** reload the page. Scores and settings are
  saved on the device, so nothing is lost.
- **No sound:** tap the screen once (devices block sound until the first tap),
  and check the mute button on the title screen.
- **A kid walked away mid-game:** in kiosk mode the game returns to the title
  by itself.
